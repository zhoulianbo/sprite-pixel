独立交互演示页已移除，首页不再根据测试查询参数切换页面。以下保留正式入口接入时的历史记录，当前流程以 `sprite-generation-workflow.md` 和实际代码为准。

## 正式入口中的视频测试开关（2026-11-01）

首页“生成动画”和角色工作台“动画”已接入实际业务流程。真实流程中的开发环境视频替换开关继续保留。

`src/config/generation/animation-video.ts` 中 `animationVideoTest.enabled = true` 时，仅在开发环境用已有 `/videos/demo.mp4` 替代供应商生成。设为 `false` 后调用真实模型；生产构建始终使用真实模型。可将 `path` 改为项目 public 目录下的测试视频路径。固定视频不随提示词或角色构图变化。

这个开关不跳过登录、项目归属、图片上传、真实积分、R2、Python 或数据库：每次点击生成视频仍按正式价格冻结并结算积分。请用测试账号验证。视频文件不会在生成阶段归档，用户点击“保存视频并选帧”时才写入既定的 `videos/YYYY-MM/{aiTaskId}.mp4`。

正式交互：

1. 选择或上传角色，画布中拖动位置，使用减号/重置/加号调整大小。整张图片按原比例限制在黄色框内；键盘方向键也可移动。提交时生成同构图的 768×768 参考图，使用现有上传接口，模型请求同步改为方形画幅。
2. 视频生成完成后停在预览，不自动抽帧、不跳转编辑器。重新生成前确认再次扣分，使用当前提示词和构图。
3. 确认保存视频后显示帧数、尺寸、播放 FPS 和循环选项。Python 实际抽帧、抠图、对齐、拼表；每次新抽帧使用独立对象，不覆盖已保存结果。
4. 可排除部分帧并预览播放，点击保存才创建 Vault 动画版本。源精灵图保存全部抽取帧，动画版本按所选帧保存裁剪坐标；“编辑与下载”沿用既有编辑器，按选定帧导出。
5. 本页最近 12 个视频入口保存在会话中；视频、抽帧草稿和已保存版本记录在服务器，刷新后恢复当前任务。关闭整个浏览器会话后，已保存动画仍在资产库中。

当前 Python 接口没有起止时间参数，因此正式界面暂时只提供实际支持的帧数、尺寸和循环选帧；独立演示页中的时间范围不会被冒充为已接通功能。抠图算法保持原实现，本次未宣称修复刀/披风颜色丢失。

服务端使用项目/任务归属校验、跨请求锁、抽帧 ID 与保存版本 ID 做重复操作保护；处理失败保留原视频和上次草稿，不再次调用模型、不退回已完成视频生成的费用。
