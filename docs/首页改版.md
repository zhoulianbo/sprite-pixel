### 目标

像 AutoSprite 一样，先给用户一个“我到底能做哪些事”的总览。

> One AI Sprite Generator for Your 2D Game Workflow

### 布局建议

做成 **6 张卡片**，2 行 3 列：

1. **Generate Characters**
   Create original 2D game characters with AI.

2. **Edit Outfits**
   Keep the same character and generate new outfit variations.

3. **Multi-Direction Sprites**
   Generate front, side, and back-facing character directions.

4. **Generate Animations**
   Turn characters into animated sprite actions.

5. **Export Sprite Sheets**
   Export organized sprite sheets for game development.

6. **Free Sprite Tools**

因为你现在的能力不止一个点，用户一进站要先看到完整能力地图，而不是先陷进某一个细节。

# 十、关于关键词 “AI Sprite Generator” 的覆盖建议

你要求主关键词覆盖率到 **1%+**，这个要控制得自然一点。

如果整页英文文案大约 **1200–1600 词**，建议：

* **AI Sprite Generator** 出现 **12–18 次**
* 重点分布在：

  * H1
  * Hero 副标题
  * 核心能力总览标题/描述
  * 5 个功能模块里至少 3 个标题或描述
  * How it works
  * Pricing
  * FAQ
  * Final CTA

### 建议写法（避免堆砌）

可以交替用这些自然句式：

* AI Sprite Generator for indie games
* use the AI Sprite Generator
* SpritePixel AI Sprite Generator
* this AI Sprite Generator helps you...
* create characters with an AI Sprite Generator

不要每句话硬塞，否则会很生硬。

# 十一、和你当前首页相比，最需要改的点

我直接说结论：

### 你现在首页的问题

1. **功能点表达不够“拆开”**，用户看完不一定知道你到底能做哪些事
2. **缺少一个完整的功能路径**：角色 → 换装 → 多方向 → 动画 → 导出
3. **免费工具没有被单独放大**
4. **信息更像“产品介绍”，不够像“可理解的工作流”**

### 改版后的提升

1. 用户更快理解产品能力
2. 首页内容更适合后续替换成 GIF 演示
3. 更利于 SEO，尤其是围绕 **AI Sprite Generator**
4. 更利于转化，因为每个功能都被单独解释了
