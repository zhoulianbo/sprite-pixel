# 角色风格与像素修复

## 产品行为

- 角色生成默认选择 `pixel-art`。风格顺序为像素画、卡通、插画、手绘、二次元、赛璐璐、低多边形、自定义。
- 自定义沿用 `none` 参数以兼容旧记录，但不继承项目的预设风格。风格约束与生成参数快照同步保存，不用提示词关键词猜测修复资格。
- Hero 图片悬停显示放大和下载；移动端按钮常显。首页、角色工作台卡片和资产库角色预览使用同一个放大弹框。
- 弹框只为生成记录明确属于像素画的角色提供“完美像素”。无法确认风格的历史/上传图片仅提供预览。
- 修复在浏览器 Web Worker 中运行，不调用模型、不增加生成积分。首页生成成功后直接展示原图，不自动修复；普通下载和保存角色同样使用当前原图。
- 用户点击放大弹框内的“完美像素”才运行修复；弹框保留原图/效果图对比，用户确认保存后才替换图片。关闭弹框不会上传草稿。
- 点击弹框中的保存才上传 PNG 并替换图片。未入库的首页生成结果仍需通过原来的角色命名/确认保存进入 Vault；入库时直接使用修复后的文件。
- 修复保存成功后自动关闭共用放大弹框；失败时保留草稿。图片区域底部浮动显示缩小、重置、放大，原图与对比图同步缩放，超出区域可用手型拖动或滚动查看，重新打开恢复适应窗口。对比状态下拖动中间手柄只移动对比分界，拖动其他图片区域则平移图片。关闭按钮为圆形背景，中心定位于弹框右上角，向外偏移半个按钮尺寸。
- 首页自动角色名按提示词内容判断：拉丁字母文本取前三个单词；其他文本最多 12 个宽度单位，半角计 1、全角计 2，纯中文最多 6 个字，不截断组合字符。手动输入的名称不受自动规则覆盖。

## 算法范围

`src/shared/lib/pixel-repair.ts` 实现轴向颜色/透明度边界统计、浮点网格间距和偏移估计、网格块代表色采样、全图色板量化及整数方格重建。网格评分按实际整数坐标的分布计算基线，避免任意图片被误判为 2px 网格；两个方向均可靠且间距一致时才使用检测结果，否则采用最长边约 256 个逻辑像素，减少细配饰被合并。

默认从原图提取最多 64 个可见 RGB 颜色，保留明暗极值及中性高光以保护眼白和轮廓。修复接口不再把提示词／项目色板强制套到原图上；色板仍可约束模型生成，修复以模型实际输出的颜色为依据。不做背景色删除；轮廓透明度整理与稳定的半透明材质分开处理，仍保留独立细小半透明特征。网格不可靠时保守合并周围至少三个相近颜色像素包围的低反差单格杂点，不抹平高反差细节。最长边不超过 128 的原生小像素图不再做网格缩减；色数已合规时逐像素保持原样。较大图片仍会检测可靠网格；无需缩减时不运行单格杂点清理。

尺寸限制为每边 4096，最多 1600 万像素；PNG 上传不超过 10 MB。默认逻辑尺寸整理后可整数放大，文件尺寸不保证与原图相同。

本算法整理像素网格，不能补回模型未画出的装备、修正人物结构或保证所有原图都更好看。保留前后对比和用户确认是必要的质量边界。

## 保存与一致性

`/api/character-images` 以 `generationId` 或 `fileId` 定位用户拥有的角色图，不接受任意源 URL。GET 可读取源图/风格信息及下载；POST 保存修复 PNG 或重试清理。

- 服务端检查项目/角色/任务归属、任务状态、风格、文件大小和 PNG 尺寸。
- 修复保存和正常角色入库共享任务锁；源版本不匹配时拒绝覆盖。
- 先上传新对象，再原子更新单个 `assetFile` 记录；保持已保存文件 ID 不变。
- `assetFile` 是当前图片的事实来源。同步 AI 任务预览地址之后才删除旧对象；清理意图与新地址一起记录，不依赖 D1 不支持的交互事务。
- 删除失败时保留新图并返回待清理标记，弹框提供重试，不再次上传或调用模型。
- 仅删除本系统管理、且未被其他有效文件记录引用的对象。外部供应商地址不尝试删除。
