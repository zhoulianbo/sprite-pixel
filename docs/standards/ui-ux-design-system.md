# SpritePixel UI / UX 设计系统

## 视觉定位与层级

默认 Dark，配色以 `src/config/style/theme.css` 的 tweakcn 语义变量为准；浅色在 `:root`，深色在 `.dark`。首页与全站使用同一套 token，不另建首页色板。圆角跟随 `--radius`，按组件视觉体量分级使用，不再以直角作为默认风格。

品牌文字固定 Sprite 为 foreground，Pixel 为 primary，屏幕阅读器读作完整 SpritePixel。点击品牌返回当前语言首页。

## 圆角层级

- `rounded-md`：默认按钮、紧凑按钮、导航 hover/active 背景、菜单项、数字输入、小型图标按钮。它是高频交互控件的默认值，不使用 `rounded-none`。
- `rounded-lg`：Hero 主操作按钮、表单内登录/注册按钮、Select Trigger、上传入口、一般内容卡片和紧凑弹出层。相邻的内部控件可用 `rounded-md`，避免内外层圆角同样大。
- `rounded-xl`：Select/Dropdown Content、预览画布、输入编辑器、定价卡片、模态窗口及中等尺寸面板。
- `rounded-2xl`：Hero 主操作区外壳或横跨多列的大型品牌面板；仅用于视觉体量明显大于普通卡片的容器。
- `rounded-full`：仅用于头像、状态圆点、圆形图标按钮，以及内容天然为单行胶囊的 badge/筛选项。普通按钮不得为了“柔和”统一做成胶囊。
- 组合容器保持层级：外层使用 `rounded-xl` / `rounded-2xl` 时，内部卡片或控件至少小一级；并排 Tab 只保留外侧角，避免重叠边框产生双圆角。
- 普通文本输入使用 `rounded-md`；登录、注册等高度为 44px 的独立表单输入使用 `rounded-lg`。嵌入 Input Group 的无边框输入可保持 `rounded-none`，由外层容器统一裁切圆角。

## 字体、布局与响应式

- 标题 Space Grotesk，正文 Inter，少量技术标签 JetBrains Mono。像素字体不用于长标题与正文。
- 描述性正文最小使用 `text-sm`（14px）。`text-xs` 仅用于 badge、编号、元数据、技术标签及空间明确受限的紧凑工具控件；普通卡片说明、功能描述、FAQ 回答和辅助说明不得使用 `text-xs` 或更小字号。
- 页面只保留一个清晰 H1；模块按 badge → title → description 的上中下顺序组织，不做三栏标题区。
- 主内容容器最大 1216px；桌面左右留白至少 20px，窄屏至少 14px。保留现有 1024px / 760px 区块断点；新通用导航使用 lg（64rem）。
- 工具和编辑器默认采用紧凑密度：桌面 Tab 高度 40–44px，常规控件 36–40px，面板内边距 16–20px、相邻控件间距 12–16px。不得用加高空行或大块留白制造层级；窄屏独立主操作仍优先保证 44px 点击区域。
- 网格响应式折叠，不通过隐藏溢出来掩盖裁切。菜单长内容使用受视口高度限制的滚动区域。
- 状态不能只靠颜色表达，配合文字或图标；菜单选择使用 aria-current，展开按钮使用 aria-expanded。

## Select 下拉控件

- 用户可见的产品界面禁止直接使用浏览器原生 `<select>`；统一使用 `src/shared/components/ui/select.tsx` 提供的 Radix Select，保留键盘导航、焦点管理与 Escape 关闭。
- Trigger 使用 secondary 表面、input 边框和 8px 圆角；hover 加深表面并以 primary 弱化边框，focus/open 使用 primary 边框和低透明度焦点环。默认高度 40px，紧凑模式 36px。
- Content 使用 popover 表面、primary/30 边框、12px 圆角、深色悬浮阴影与轻微背景模糊；高度不得超过可用视口，长列表允许滚动。
- Item 的 hover、focus、highlight 统一为 `bg-primary/10` + `text-primary`，当前选项同时显示 primary 勾选图标，禁用项必须保持不可交互状态。
- 表单中的 Select 可根据容器拉伸宽度；提示词编辑器里的参数 Select 采用紧凑标签 + 当前值形式，椭圆胶囊、`bg-secondary/55`、宽度随内容自适应并左对齐，不另起一整行占用垂直空间。选项值来自 `src/config/generation`，展示文案读取 `generation` 多语言表，不在组件内写死。

## 导航行为

- 一级：首页、功能、工具、画廊、价格；子项遵循 project-brief.md。
- 桌面一级导航和登录按钮统一为 `h-8 rounded-md`；hover、focus、active/current 和菜单展开状态的背景只覆盖这 32px 高度，不撑满 Header。下拉面板使用 `rounded-lg`，下拉项使用 `rounded-md`。
- 桌面下拉使用现有 Radix NavigationMenu，支持键盘、焦点和 Escape；移动端通过按钮和 Accordion 展开。
- 选中由规范化 pathname + hash 精确匹配。根路径不得匹配所有页面；有锚点时 Home 不同时选中。
- 子项选中时父级「工具」高亮；hover/open 是临时反馈，关闭后保留当前位置状态。
- 点击子项后关闭菜单；返回/前进、直接打开锚点、切换语言仍能识别位置。锚点目标预留固定 Header 高度。
- 暂无独立功能页时可指向真实存在的功能介绍锚点，必须在项目简报标明临时映射。

## Hero 与资产展示

- Hero 主背景使用 `bg-vault-navy`（跟随 theme.css）；覆盖低对比度 48 × 48px 方格，网格在文字/操作层后方，pointer-events-none，不接收焦点。首页布局用 Tailwind，颜色只用主题语义变量。Hero 主工作区使用 `rounded-2xl`，输入编辑器与预览使用 `rounded-xl`，Tab 和主操作按钮使用 `rounded-lg`。
- 首页提示词工作台采用紧凑编辑器布局：生成角色的参考图、生成动作的角色图均为输入框右侧正方形按钮；参数 Select 为椭圆胶囊（`bg-secondary/55`），以内嵌控件组放在输入框左上角，宽度随内容自适应并左对齐；文本输入位于其下。操作区整体宽度比原先左侧参考图栏少一列。表单聚焦边框使用带透明度的 primary，与外层实色金边区分。当前项目以文件夹图标 + 项目名称显示在输入框左下角，默认选择「默认项目」，其下拉菜单提供「添加项目」。主生成按钮固定在输入框右下角。预览区域与表单等高，不再强制正方形。生成动作成功后在预览下方提供播放/暂停、1–24 FPS 调整和有效帧总数；保留生成网格但自动跳过完全透明帧，详情入口统一为「编辑与下载」。
- 生成角色与生成动作共用上述结构；Tab 高度不超过 44px。生成角色保留带图标的「随机灵感」，从 10 条预设灵感中随机切换并以打字效果填入输入框。所有选项不得在输入框外另占一行。
- 方格采用 Tailwind 背景线性渐变；这是界面结构，不是替代真实游戏资产的插画。
- Hero 小浣熊 Canvas 表达上下文 → 批量资产 → 动作测试 → 入库。演示不宣称已执行真实生成/保存。
- Sprite Sheet 保持每帧画布、基线、裁切框一致；禁止串入邻帧或切掉剑光、尾巴。实际观察所有阶段，不能只验证 PNG 有 alpha 就声称无黑底。
- 像素图禁用平滑并保持比例；不要通过不同 x/y 比例拉伸 Canvas。离屏和隐藏标签页暂停，减少动态效果使用静态帧；资源加载失败有明确反馈。
- 公共图片保存项目内，避免盗用游戏 IP。后续图像占位可继续保留明确示意，不能伪装成真实用户案例。

## 功能界面状态

- 生成：idle、validating、queued、processing、success、failed；重复点击要防重，不使用假完成百分比。
- 批量：逐项可见进度与错误，重试只针对失败项，完成项可直接保存。
- Vault：空状态引导生成；loading、error、无筛选结果分别处理；删除有清晰目标反馈。
- 模态窗口与菜单遵循现有 UI 组件的焦点管理。键盘能完成主操作，移动端主要点击区域建议至少 44px。

## 验收

桌面和 390px 窄屏检查：文字可读、无横向溢出、方格可见且不抢正文、菜单不裁切、圆角层级清晰、hover/focus/selected 颜色一致。中英文至少各检查一次新增内容。记录实际观察和未执行项，不把历史 QA 的 passed 复制成当前结论。

## Free Tools 页面与工作台（2026-09-08）

- Maker / Splitter 的标题、说明和上传区属于同一个 Hero，中间不加横向分隔线。未上传时只显示上传框、Maker 输入模式和「去生成素材」入口（跳转首页），不提前展示空参数栏。Hero 分区不用 overflow-hidden 裁切整块内容，避免展开工作台后标题滚出且无法滚回。
- 上传成功后展开工作台：桌面左侧上传与纵向帧列表、中间大预览、右侧参数与导出；工作台高度适应视口，帧列表与长参数各自滚动。手机端依次为预览、帧列表、参数与导出。大屏下工作台已在视口内时不自动滚到操作区顶部，以免挡住标题和描述。
- 预览使用棋盘格、按钮缩放（左侧重置为适应窗口，不使用滚轮缩放）与独立动画视图。Maker 的列数、边距、间距、帧对齐立即反映到预览；导出 PNG 在后台生成。主下载按钮固定在右侧参数区下方；Maker 导出可选 JSON Hash / JSON Array / CSS / XML / GIF，勾选后随 PNG 打成 ZIP。右侧 Maker 帧对齐为三个并排按钮；可选裁掉透明边（默认关）。Splitter 上传普通图片后根据图片尺寸自动估算规则网格，结果仍允许手动调整；切分方式为两个并排按钮，行列/尺寸与间距偏移使用与 Maker 相同的单行数字控件；左侧选帧为复选框加「全选/全不选」文案，以及单独的「帧范围」按钮。勾选全选、取消则全不选，部分选中时复选框为中间态；帧范围弹出起始/结束与确定。导入精灵图表时默认不选中完全透明帧；整行含复选框区域均可点击切换选中。切分问号用浮层说明网格，不被参数滚动裁切。调整切分参数时网格叠加立即更新，帧提取在后台防抖进行，不锁定右侧设置。导出标题旁问号点击后以圆角气泡说明引擎导入，用阴影和略亮底色与导出区区分。能单行展示的控件保持单行。追加帧虚线使用 accent-foreground，hover 时加深填充。Splitter 不提供发送到 Maker 的按钮。
- 帧手柄支持鼠标拖动，键盘聚焦后直接用 ↑ / ↓ 移动；重排计算结束后恢复手柄焦点，允许连续操作。
- 页下说明采用三步流程、交错图文演示、应用场景、参数说明与 FAQ。模块样式与首页一致：通栏分区横线、1216px 内容壳、大标题字号、`rounded-lg` 内容卡片与 FAQ 通栏列表。演示优先复用项目自有浣熊素材，明确作为功能示意，不冒充用户案例或游戏引擎验收。
